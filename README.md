# تحصين · الرقية الشرعية

تطبيق ويب بسيط يعرض الرقية الشرعية مرتّبةً صفحةً صفحة:

1. التحريج
2. التحصين
3. سورة الفاتحة
4. سورة البقرة — أولها (1 – 5)، ثم آية الكرسي (255)، ثم خواتيمها (285 – 286)
5. سورة الزلزلة
6. سورة الحاقة
7. سورة الدخان
8. سورة الصافات
9. سورة الأنفال

## المزايا
- **القراءة** (الوضع الأساسي): نص القرآن بخط مصحف المدينة برواية حفص.
- **الاستماع**: تلاوة آيةً آية مع تظليل الآية الجارية، واختيار القارئ، وتكرار الصفحة (1 / 3 / 7)، والانتقال التلقائي.
- حفظ تقدّم اليوم تلقائياً، وتكبير الخط، ومظهر ليلي ونهاري.
- يعمل كتطبيق على الجوال (إضافة إلى الشاشة الرئيسية) ويفتح النص دون إنترنت بعد أول زيارة.

## الإشعارات (أندرويد وآيفون)
تذكير «هل قرأت التحصين؟» أربع مرات يومياً (5:13، 11:13، 17:13، 23:13 بتوقيت السعودية) عبر Web Push.
- **للمستخدم:** الإعدادات ← الإشعارات ← تفعيل ← السماح. بدون حساب ولا تسجيل دخول. على آيفون يجب أولاً إضافة التطبيق إلى الشاشة الرئيسية (iOS 16.4+).
- **الخادم:** Cloudflare Worker في المجلد `worker/` (يُنشر تلقائياً من هذا المستودع عبر Workers Builds). يحفظ اشتراكات الأجهزة في Durable Object،
  ويُنشئ مفاتيح VAPID بنفسه عند أول تشغيل، ويرسل التذكير على جدول cron، ويحذف الأجهزة التي انتهى اشتراكها.
- عنوان الخادم في `data/push.json` (`{"api": "https://…workers.dev"}`).

## المصادر
- **نص القرآن:** مجمع الملك فهد لطباعة المصحف الشريف — نص حفص العثماني، الإصدار 3.0، عبر مجموعة بيانات
  [quran-text](https://github.com/quran-ws/quran-text) (CC BY 4.0). طوبق النص آيةً آية مع نص
  [موسوعة القرآن الكريم QuranEnc](https://quranenc.com) ونص [Tanzil](https://tanzil.net) دون أي اختلاف في الحروف أو التشكيل.
- **الخط القرآني:** KFGQPC HAFS Uthmanic Script v3.0 من مجمع الملك فهد، يُوزَّع دون تعديل وفق رخصته (`fonts/KFGQPC-FONT-LICENSE.txt`).
- **خطوط الواجهة:** Amiri و Aref Ruqaa (رخصة SIL OFL).
- **التلاوات الصوتية:** [EveryAyah](https://everyayah.com) (تُشغَّل مباشرة من موقعهم).
